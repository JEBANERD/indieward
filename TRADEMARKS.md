# IndieWard name and fork policy

IndieWard's code is MIT-licensed (see [LICENSE](LICENSE)). Fork it, change it, ship it, sell it. The MIT licence covers the code. It does not cover the name.

"IndieWard" (and any logo the project adopts) is used by the project maintainer as a trademark for this software. The name is not registered yet. If it is registered later, this file will say so.

## Why the name has rules

IndieWard is built so that it can't be turned against the creators it protects. Anyone who sees the name should be able to count on these safety rules:

1. **Verification gate.** Registering, trapping, checking, certifying and packaging all require a verified store link, so nobody can claim someone else's game.
2. **No sending.** IndieWard never sends email, submits forms or contacts stores for the user. The creator reviews and sends every notice themselves.
3. **Honest evidence.** Every check report keeps the similarity disclaimer (it cannot show whether an AI was used), the Strong / Supporting / Weak labels, and the "don't file" advice for mechanics-only reports.
4. **Inert traps.** Trap markers never affect gameplay, performance, the network or player data.

## What you may do

- Fork, modify and redistribute the code under MIT.
- Call a build "IndieWard" if it keeps all four rules above, behaves the same as this project from the user's point of view, and doesn't suggest the maintainer endorses it.
- Say truthfully that your project is "based on IndieWard", "a fork of IndieWard" or "compatible with IndieWard certificates", as long as your project has its own name.
- Use the name to talk about IndieWard: in articles, tutorials, reviews, comparisons and package listings that point to this project.

## What needs a different name

A build that removes or weakens any of the four rules must not use the name "IndieWard", a confusingly similar name, or the IndieWard logo. Rename it and say plainly that it is not IndieWard. For example, a build that skips store verification or files takedowns automatically has to go by another name.

Also don't use the name for anything that suggests official status it doesn't have, such as an "official IndieWard" store listing, hosted service or support channel.
