# P1-01: CI green on Linux, Windows, macOS

## The Job
Make `.github/workflows/ci.yml` pass on all four matrix jobs. Read the latest failing run logs with `gh run list --workflow ci.yml` / `gh run view <id> --log-failed` (gh is authenticated in the runner). Fix the code, not the tests, unless a test is wrong about the platform (e.g. path separators, file locking on Windows, ffmpeg codec availability on macOS). If the `plugin` job fails only because `claude plugin validate` needs login, make that job `continue-on-error: true` and say so in the PR.

## The Why
Jasper runs Windows. Packaging and support depend on this.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Don't skip or delete tests to get green; if a test truly can't run on a platform, mark it `skipif` with a reason and explain in the PR.

## Done Means
- All ci.yml jobs green on the PR. Any `skipif` added is listed with its reason.
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
