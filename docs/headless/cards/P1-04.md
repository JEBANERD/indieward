# P1-04: Dogfood on one of Jasper's real games (needs Jasper)

Jasper runs, on his Windows PC, in one of his real game folders:
`indieward doctor` → `indieward init` → paste the code into the store page → `indieward verify page` → `indieward register` (art, audio, a trailer, code, text) → `indieward cert` → `indieward traps new` for the next build → export → `indieward build register`.
He listens to one watermarked music track and looks at two watermarked images at 100% zoom.

The worker skips this card. When Jasper opens an issue with his notes, `@claude` turns each problem into a new card.
