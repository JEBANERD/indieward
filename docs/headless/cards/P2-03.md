# P2-03: Unity IL2CPP via GameCI (needs Jasper)

Needs a Unity licence activated for CI (`UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD` secrets; see game.ci "Activation"). Once Jasper adds them, set this card to `todo`.

The Job (for the worker after that): add an `engines / unity` job using `game-ci/unity-builder` that builds a tiny project with the generated `.cs` + `link.xml` for Linux IL2CPP, then runs `indieward build register` on the output and confirms traps are found in `global-metadata.dat`. Skip cleanly when the secrets are absent.
