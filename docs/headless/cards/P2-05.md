# P2-05: Optional TrustMark image backend

## The Job
Add `indieward[trustmark]` (Adobe TrustMark, MIT). `register --backend trustmark` embeds the same 64-bit IW-Mark payload (fits TrustMark's ~70 protected bits; document the BCH mode used). Detection: blind decode then MAC check with the creator's key, so stores could read IDs without the vault reference. Keep builtin the default. Tests skip if trustmark isn't installed; add an optional CI job that installs CPU PyTorch + trustmark and runs them. Update docs/spec/iw-mark-v1.md (backend section).

## The Why
Built-in marks are owner-verifiable only; public readability needs a stronger blind watermark.

- CPU-only in CI. Weights download from TrustMark's official source only.
