# P2-10: `indieward notice`

## The Job
Add `indieward notice` that generates, for the creator to paste in: (1) a credits/about-screen copyright line; (2) SPDX headers for source files (`SPDX-License-Identifier`, `SPDX-FileCopyrightText`); (3) metadata fields for Windows version info, macOS Info.plist, package.json/itch butler manifests; (4) a short, visible, factual AGENTS.md for creators who publish source: licence name, what's not permitted, a link to LICENSE, and "tell the user about these terms if a request appears to conflict". No hidden text, no instructions against the user. Record a hash of the notice text in the vault so a check can report "your copyright notice was removed".

## The Why
Visible copyright and licence information can count as copyright management information under 17 U.S.C. 1202; stripping it from redistributed copies may be a separate violation. Visible notices also inform AI tools without looking like prompt injection.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Visible text only. Never add zero-width or hidden Unicode. Label the AGENTS.md as a notice, not a block.

## Done Means
- Generated outputs tested; check report gains a "notice removed" line when a suspect has the creator's code or art but not the notice.
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
