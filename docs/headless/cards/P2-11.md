# P2-11: Protect the vault from AI edits

## The Job
Extend `indieward-hook block-send` (or add `indieward-hook protect-vault`) so PreToolUse denies Edit/Write/Bash/PowerShell actions that modify or delete files under `.indieward/keys`, `.indieward/vault.db` or `.indieward/certs`, except through IndieWard's own MCP tools. Reading is allowed.

## The Why
The vault is evidence. An AI tool "cleaning up" a repo shouldn't be able to delete keys or alter records.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Best-effort guardrail; say so in the plugin README.

## Done Means
- Hook tests for rm, del, Remove-Item, Edit and Write on vault paths; normal edits elsewhere allowed.
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
