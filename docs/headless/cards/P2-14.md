# P2-14: Pick code-comment rules by file type

## The Job
`fp_code._COMMENT_RE` strips comments with one regex for every language. It includes Lua `--` line comments and Python/GDScript `#` line comments, so in JavaScript the first `i--`, `x--` or `"#fff"` is read as a comment start and deletes the rest of the line. In a minified bundle the whole file is one line, so almost nothing is left to fingerprint.

Measured on npm packages while working on P2-08 (#23), fingerprints from the minified file versus the unminified one:
- phaser 4.2.1: `phaser.min.js` 57 vs `phaser.js` 44,894
- howler 2.2.4: `howler.min.js` 125 vs `howler.js` 2,412
- matter-js 0.20.0: `matter.min.js` 218 vs `matter.js` 5,477

So copied minified JavaScript, which is how web games ship, is close to invisible to the code category of `indieward check`.

Fix:
- Choose comment rules by file extension:
  - `--` and `--[[ ]]` only for `.lua`/`.luau`;
  - `#` only for `.py`, `.gd`, `.gdscript` (and other `#`-comment languages);
  - `//` and `/* */` for JS/TS/C#/C/C++/Haxe/GML/Java.
  - Keep a safe default for unknown extensions.
- Pass the file name or a language hint through `tokens_with_lines`, `fingerprint_text_blobs` and `fingerprint_files`. Callers in `check.py`, `registry.py` and `traps.py` already have names.
- Don't treat `//` or `#` inside JS string, template or regex literals as comments.
- Rebuild `src/indieward/data/common.json` with `python scripts/build_common.py` (from P2-08), because library fingerprints change.

## The Why
Web games ship minified bundles. A clone of a web game is usually a copied or lightly edited bundle, and today the code check barely sees it.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Fingerprints for languages whose rules don't change (Lua, GDScript, Python) must stay identical. Pin them with tests.
- JS fingerprints change, so builds registered earlier won't match as well until they're re-registered. Say so in the PR and in the creator guide's release notes or README.

## Done Means
- A test shows a minified JS sample yields fingerprints comparable to its unminified source (same order of magnitude), and that a copied minified bundle scores high against the registered original.
- Lua and GDScript fingerprint outputs are unchanged (pinned samples).
- `common.json` rebuilt; `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
