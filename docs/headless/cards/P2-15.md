# P2-15: MCP tool for `indieward notice`

## The Job
P2-10 added `indieward notice` (`src/indieward/notice.py`) as a CLI command only. Add a matching MCP tool in `src/indieward/mcp_server.py` so the Claude plugin can generate a creator's visible copyright notice:

- `copyright_notice(project_dir, licence="", year=0, holder="")`. Call `notice.generate()` with the same defaults as the CLI:
  - licence: all rights reserved;
  - year: first publication year, else this year;
  - holder: the vault's creator.
  Return the credits line, SPDX headers, metadata fields and the AGENTS.md text. Like the other tools, wrap it in `_safe` and use `find_vault`.
- **It returns text only.** It must not write AGENTS.md or any file in the creator's project. The tool's description should say the user pastes or saves the text themselves (the CLI's `--agents-md` stays CLI-only).
- Mention the tool in the `protect-setup` skill (`plugin/skills/protect-setup/`) as an optional step after registration, with the same plain description as the creator guide.

Out of scope: MCP tools for `watch` and `traps inject`. `watch` sends strings to outside services and `inject` writes to the creator's files, so both need their own design for consent prompts.

## The Why
Plugin users never touch the CLI. Without the tool, the plugin can't offer the notice, which also feeds the check report's "notice removed" line.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Visible text only, as in P2-10. No new network calls. No file writes from the tool.

## Done Means
- A test in `tests/test_plugin.py` lists the tool, calls it on a fresh vault, and gets the credits line and AGENTS.md text back. It also checks that the tool wrote no file outside the vault and that the notice hash was recorded.
- `claude plugin validate plugin --profile directory --strict` still passes if run (list it under "Jasper by hand" if the CLI isn't available).
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
