# P2-16: `traps inject` for Godot and Unity localization files

## The Job
`indieward traps inject` (P2-09) handles CSV/TSV, JSON and gettext `.po`. Godot already reads translation CSV and `.po`, so those projects are covered. Two common formats aren't:

1. **Godot `.tres` translation resources** (`[gd_resource type="Translation" ...]`, or `OptimizedTranslation`, which stores hashed messages and should be refused with a clear message). Add the build's string traps as new messages in a plain `Translation`, matching the file's key style.
2. **Unity Localization string tables** (the `com.unity.localization` package). A table collection is a **Shared Table Data** `.asset` (YAML, `m_Entries` with `m_Id`, `m_Key`) plus one **String Table** `.asset` per locale (`m_TableData` with `m_Id`, `m_Localized`).
   - Add each trap as a new shared entry with a fresh unique `m_Id`, and a matching entry in every locale table of the collection.
   - Take the collection folder (`--into <folder>`) so all of its files change together.
   - Keep Unity's YAML header, tags and `fileID`/`guid` references byte-for-byte. Append entries only.

Same rules as P2-09:
- show a diff and write nothing without `--apply`;
- back up first;
- never change existing entries;
- refuse formats a game might iterate over and show.

Check the exact file layouts against the official docs before coding:
- Godot: the `Translation` class and the `.tres` text resource format.
- Unity: the Localization package manual pages for String Tables and Shared Table Data.

Cite the pages in the PR.

## The Why
Godot and Unity are two of the engines IndieWard supports. Hiding traps in their native localization files is harder for a refactor to spot than a separate snippet, and today creators on those engines have to convert to CSV first.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Injected keys must never be displayed or read by gameplay. They're only reachable by a key the game never asks for.
- No Unity Editor or Godot is needed to run the default tests. Use small fixture files, written by hand from the documented format and kept under 20 KB.

## Done Means
- Tests for a Godot `.tres` translation and a Unity table collection (one shared table and two locales):
  - entries are added;
  - existing bytes are unchanged (a character-level diff contains only insertions);
  - `m_Id` values are unique;
  - a second injection is refused;
  - `traps verify` finds the injected traps in a folder containing the files.
- If the `engines` Godot job can import the `.tres` and export a pack, add a test there that `traps verify` finds the traps in the `.pck`. Otherwise list it under "Jasper by hand", along with opening the Unity tables in the Editor.
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
