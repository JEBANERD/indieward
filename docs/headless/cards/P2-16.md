# P2-16: `traps inject` for Godot `.tres` translations

**Split (2026-11-04):** the Unity Localization half moved to P2-28, so this card can start as soon as the Godot sample is in.

## The Job
`indieward traps inject` (P2-09) handles CSV/TSV, JSON and gettext `.po`. Godot already reads translation CSV and `.po`, so those projects are covered. Godot `.tres` translation resources aren't:

- `[gd_resource type="Translation" ...]`: add the build's string traps as new messages, matching the file's key style.
- `OptimizedTranslation` stores hashed messages: refuse it with a clear message.

Same rules as P2-09:
- show a diff and write nothing without `--apply`;
- back up first;
- never change existing entries;
- refuse formats a game might iterate over and show.

Build the parser from the committed sample (below), and check it against Godot's `Translation` class docs and the `.tres` text resource format page. Cite the pages in the PR.

## The Why
Godot is one of the engines IndieWard supports. Hiding traps in its native translation resources is harder for a refactor to spot than a separate snippet, and today creators with `.tres` translations have to convert to CSV first.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Injected keys must never be displayed or read by gameplay. They're only reachable by a key the game never asks for.
- No Godot is needed to run the default tests. Use the committed sample plus small hand-written fixtures, each under 20 KB.

## Done Means
- Tests for a Godot `.tres` translation:
  - entries are added;
  - existing bytes are unchanged (a character-level diff contains only insertions);
  - an `OptimizedTranslation` is refused;
  - a second injection is refused;
  - `traps verify` finds the injected traps in a folder containing the file.
- If the `engines` Godot job can import the `.tres` and export a pack, add a test there that `traps verify` finds the traps in the `.pck`. Otherwise list it under "Jasper by hand".
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.

## Sample (unblocked 2026-11-10)
The samples are committed under `tests/fixtures/inject/`: a `Translation` and an `OptimizedTranslation` saved by Godot 4.4.1 (not 4.3, which wasn't installed; both write `format=3`). Read `tests/fixtures/inject/README.md` first. A plain `Translation` can't hold message context, so there's no context sample and inject doesn't need to handle context in `.tres`.
