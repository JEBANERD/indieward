# P2-18: More libraries in the common-material index

## The Job
P2-08 shipped `src/indieward/data/common.json` with code fingerprints for three, phaser, pixi.js, howler, matter-js and lodash, built by `scripts/build_common.py` from pinned npm tarballs. Add more libraries that web games commonly bundle. All are permissively licensed (checked on the npm registry, 2026-10-31):

| npm package | Version seen | Licence | Notes |
| --- | --- | --- | --- |
| `@babylonjs/core` | 9.33.1 | Apache-2.0 | Large: fingerprint only the main bundle(s), see the size budget |
| `react`, `react-dom` | 19.3.1 | MIT | `react-dom` holds most of the code |
| `vue` | 3.5.44 | MIT | `dist/vue.global*.js` / `vue.esm-browser*.js` |
| `jquery` | 4.0.0 | MIT | `dist/jquery*.js` |
| `kaboom` | 3000.1.17 | MIT | game engine |
| `excalibur` | 0.32.0 | BSD-2-Clause | game engine |

- Pin each version in `LIBS` with a file regex, as the existing entries do. The build script already checks each tarball's sha512 `integrity`.
- Re-run `python scripts/build_common.py` and commit the regenerated `common.json`.
- If a package ships its bundle under a different path, adjust its regex and say so in the PR.

## The Why
React, Vue and jQuery games, and Babylon/Kaboom/Excalibur ones, currently count shared library code as "copying" unless the creator runs `common add` themselves.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Fingerprints only, never library source. Pinned versions, integrity-checked, reproducible output (two runs give the same bytes).
- **Size budget:** keep `common.json` under 4 MB. If a library would push it over, fingerprint fewer of its files (the main browser bundle only) and note that in the PR.
- The detection rule stays as is (a library is excluded only when the suspect has at least 10% and at least 200 of its fingerprints). Report the cross-library overlaps you measure, as P2-08 did, so the threshold can be re-checked.

## Done Means
- `common.json` rebuilt with the new libraries, under 4 MB, and byte-identical across two runs.
- `tests/test_common_index.py` updated for the new library list, still passing.
- A measured table in the PR: each new library's fingerprint count, and its overlap with each existing library and with IndieWard's own source.
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
