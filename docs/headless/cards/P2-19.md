# P2-19: Detect bundled libraries by their unique fingerprints

## The Job
`common_index.detect()` counts a library as bundled when a suspect contains at least 10% (`MIN_SHARE`) and at least 200 (`MIN_SHARED`) of **all** that library's fingerprints. Big libraries share generic JavaScript, WebGL and maths patterns, so one library's bundle can cross the threshold for another.

Measured in P2-18 (#43) with all 13 indexed libraries, as the share of library B's fingerprints that a bundle of library A contains:

| Bundle (A) | Also trips (B) | Share of B | Real? |
| --- | --- | --- | --- |
| phaser | matter-js | 47.6% | yes: Phaser bundles Matter's physics |
| react-dom | react | 25.2% | yes: shared code |
| pixi.js | excalibur | 16.3% | no: generic overlap |
| babylonjs | excalibur | 14.8% | no |
| three | excalibur | 12.0% | no |
| excalibur | pixi.js | 10.5% | no |

Change detection to use each library's **unique** fingerprints, meaning those that appear in no other indexed library:
- Compute the unique set once in `load()`. It's cached, so this is cheap.
- A library is bundled when the suspect has at least `MIN_SHARE` and at least `MIN_SHARED` of its *unique* fingerprints. Keep both constants unless the measurements below say otherwise.
- When a library is detected, still exclude **all** its fingerprints, as today. Only the detection test changes.

In the same measurement, every library keeps 43–88% of its fingerprints as unique, and the false trips drop to none for all 13 libraries. Real bundles still detect: a Phaser bundle is excluded as Phaser, and the Matter code inside it is covered because it's also in Phaser's set.

## The Why
A false detection drops another library's fingerprints from the comparison. That's a small effect today (indexed libraries overlap ordinary code by under 0.5%), but it grows with every library added, and the report then names libraries the suspect doesn't ship.

- Scores must not go up for a real copy. Re-run the existing end-to-end clone test and the three.js test (`INDIEWARD_THREE_JS`).
