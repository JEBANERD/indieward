# P2-25: `traps inject` safety: gate JSON objects, unique backups, a restore command

## The Job
P2-09 (#25) hides build traps in the creator's own data files. Three gaps on main (105bac5), all in `src/indieward/inject.py`:

1. **JSON objects aren't gated.** CSVs that aren't localisation tables and JSON lists of rows need `--rows`, because a game that loops over them would show or load the trap. A JSON object takes a different path: inject adds keys to its largest string table (`_inject_json`, the `isinstance(obj, dict)` branch) with no flag. An item registry like `{"items": {"sword": "Sword", "bow": "Bow"}}` is a string table, and a game that lists every item would show the trap. Require `--rows` for JSON objects too, unless the table looks like localisation: the file name or the table's key path contains a locale code (`en`, `en_US`, `fr-FR` …) or one of `locale`, `lang`, `i18n`, `l10n`, `strings`, `translations`. Use the same warning text (`ROWS_WARNING`).
2. **Backups can overwrite each other.** The backup name is a timestamp to the second plus the file name, so two injects into the same file within a second keep only the last original. Make the name unique (for example, add the file's SHA-256 prefix, or refuse to overwrite).
3. **No restore.** Undoing an inject means finding the backup and copying it back by hand. Add `indieward traps inject --restore <file>`: it finds the latest injection log entry for that file, checks that the file still has the logged SHA-256 (refuse with a plain message if it was edited since), shows what it will do, and writes only with `--apply`. Add it to the MCP plan/apply pair from P2-17 only if it fits that pattern cleanly; otherwise list it under "Found while working".

## The Why
Traps must stay inert. A trap that shows up in a shop list breaks that promise in the player's view, and an injection the creator can't cleanly undo makes them wary of the feature.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- Keep every current refusal. Don't make any file type easier to inject into than it is today.
- Restore writes only the vault's own backup, only to the logged path, only with `--apply`.
