# P2-27: First real run of the UE5 trap check

**Needs Jasper:** needs Unreal Engine 5 on a Windows machine.

## The Job
P2-04 (#5) shipped `scripts/ue5_check.ps1` and a guide, but the PR says the script "has not been run or even parsed".

1. Parse-check first: `pwsh -NoProfile -Command "$null = [scriptblock]::Create((Get-Content scripts/ue5_check.ps1 -Raw))"`. Fix syntax errors in a PR before going further.
2. Follow `docs/engines/ue5.md` with a blank UE5 project: `indieward traps new --engine ue5`, add the files as the guide says, package a Development build, then run the script exactly as the PR describes.
3. Success is what #5 promised: the script prints the trap count found and PASS. Record the UE5 version, the packaging settings (pak/IoStore, compression, encryption), and the output.
4. If traps don't survive a setting, add it to the guide's "what breaks traps" list, the way P2-01 did for Godot's GDScript export mode.

## The Why
UE5 is the only engine with no automated export test. Until it runs once, the guide is a guess.

## Done Means
- One recorded passing run, with versions and settings, pasted into a PR that fixes whatever the run turned up (or a PR that changes only this card, if nothing needed fixing).
