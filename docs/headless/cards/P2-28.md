## The Job

- Add each trap as a new shared entry with a fresh unique `m_Id`, and a matching entry in every locale table of the collection.
- Take the collection folder (`--into <folder>`) so all of its files change together.
- Keep Unity's YAML header, tags and `fileID`/`guid` references byte-for-byte. Append entries only.

Reuse whatever P2-16 adds, and keep P2-09's rules: diff without `--apply`, back up first, never change existing entries. Check the layout against the committed sample and the Localization package manual pages for String Tables and Shared Table Data. Cite the pages in the PR.
