# P3-01: Static guide site + Cloudflare Pages workflow

## The Job
Build a small static site from docs/creator-guide.md, docs/spec/iw-mark-v1.md and README (plain HTML + one CSS file, or Astro if simpler). Add `.github/workflows/site.yml` that deploys to Cloudflare Pages with `cloudflare/wrangler-action`, gated on `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets (skip cleanly when absent).

## The Why
Creators need a readable guide without cloning the repo.

## The Guardrails
- Everything in docs/headless/RUNNER.md.
- No analytics or trackers. Every legal claim keeps its official link.

## Done Means
- Site builds in CI; deploy step skips without secrets; PR has screenshots (Playwright) of the home and guide pages.
- `python -m pytest -q` passes. QUEUE.md row set to `in-review`. PR body written per RUNNER.md.
