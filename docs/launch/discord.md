**IndieWard is out: free anti-clone tools for indie devs** 🛡️

Up front: it can't stop anyone copying or decompiling your game, and it can't tell if an AI was used. Nothing can. What it does is make proof cheap and takedowns fast.

• **Register** art, audio, video, code and builds: a signed certificate with two independent timestamps
• **Watermark** images, audio and video; hide inert **trap markers** in builds (no gameplay, network or player-data effects)
• **Check** a suspect: Strong / Supporting / Weak per category, and "don't file" for mechanics-only matches
• **Draft** takedowns for Steam, itch.io and Roblox. You send them; IndieWard never does

Runs locally, MIT licensed, not legal advice.

```
pipx install "indieward[mcp] @ git+https://github.com/JEBANERD/indieward"
indieward doctor
```
